# دیمۆی سەر شانۆ — ڕێنمایی ڕۆژی پێشکەشکردن

دیمۆیەکی زیندووی ٣–٤ خولەکی: ڕاپۆرت ← AI پاشماوە دەژمێرێت و پلەی پیسی دەدات ← شوێنەکە لەسەر نەخشە سوور دەبێت ←
مۆبایلی دووەم پاکی دەکاتەوە بە ڕێنماییەکی هەڕەمەکی ← سەلماندن ← سەوز لەسەر نەخشە و داشبۆرد ← خاڵ ← لیگ.
هەمووی لەسەر یەک لاپتۆپ و یەک هۆتسپۆت کار دەکات؛ ئینتەرنێتی هۆڵ پێویست نییە.

## دابەشکردنی کار (پێشنیارە، بەدڵی خۆتان بیگۆڕن)

| کەس | ئەرک لە دیمۆدا |
| --- | --- |
| ڕەند (Rand) | قسەکەر؛ لاپتۆپ: سێرڤەر، preflight، فەرمانی فێڵ |
| دەریا (Darya) | مۆبایلی A: هاوڵاتیی ڕاپۆرتکەر |
| دادیار (Dadyar) | مۆبایلی B: هاوڵاتیی پاککەرەوە |
| زانکۆ (Zanko) | داشبۆردی شارەوانی لەسەر پرۆجێکتەر |
| حەمزە (Hamza) | ڕوونکردنەوەی ژمارەکانی AI |

## ١. ئێوارەی پێشوو

- **مۆدێل:** بە `tools/evaluate.py` بڕیار بدەن کام مۆدێل: ئەوەی لەسەر وێنەی سلێمانی ڕاهێنراوە، یان ئەگەر باشتر نەبوو
  مۆدێلی گشتیی پاشماوە. فایلەکە بخەنە `backend/models/`. ژمارە ڕاستەقینەکانی هەڵسەنگاندن بۆ حەمزە بنووسنەوە
  (تەنها ئەوانەی `evaluate.py` دەریدەکات؛ هیچ ژمارەیەک دامەنێن).
- **فایلی `.env`** لە `backend/` (git پشتگوێی دەخات). `SECRET_KEY` یەک جار دروست بکە و مەیگۆڕە، دەنا ئەگەر سێرڤەر
  دووبارە دەست پێبکاتەوە مۆبایلەکان دەردەکرێن. `STAFF_PASSWORD` وشەی نهێنیی داشبۆردە (`seed.py` بەکاری دەهێنێت):
  `staff1234` ی بنەڕەت لە README دایە، بۆیە هەر کەسێک خوێندبێتیەوە دەتوانێت پاککردنەوە پەسەند بکات:

  ```bash
  cd backend
  cat > .env <<'EOF'
  export DATABASE_URL=postgresql://gl:gl@localhost:5432/greenlegacy
  export MODEL_PATH=models/slemani.pt      # یان models/yolov8m-seg.pt (مۆدێلی گشتیی پاشماوە)
  export LITTER_CLASSES='*'
  EOF
  echo "export SECRET_KEY=$(python -c 'import secrets; print(secrets.token_hex(32))')" >> .env
  echo "export STAFF_PASSWORD=$(python -c 'import secrets; print(secrets.token_hex(6))')" >> .env
  grep STAFF_PASSWORD .env       # ئەم وشە نهێنییە لەسەر کارتی شارەوانی (هی زانکۆ) بنووسە
  ```

  `DETECTOR_KIND` و `SIM_CAMERA` **نابێت** لەم فایلەدا بن.
- **ستیکەری QR:** `python tools/make_qr_stickers.py 12` ← `qr_stickers.png` لەسەر A4 چاپ بکە، ببڕە، `GL-BIN-001`
  بلکێنە بە زبڵدانی دیمۆوە (ستیکەرەکان ~٩ سمن؛ بە قەبارەی ١٠٠٪ چاپیان بکە). بە مۆبایلی B لە ~٣٠ سمەوە تاقی بکەرەوە و یەک چرکە بیوەستێنە؛ شوێنەکە لە ١٫٥ مەتر یان زیاترەوە تۆمار بکە، بۆ ئەوەی ستیکەرەکە زوو نەخوێندرێتەوە.
- **کەرەستە:** ٦–١٠ بوتڵ، قوتوو و کیسەی بەتاڵ و پاک، کیسەیەکی زبڵ و دەستکێش بۆ پاککەرەوە، و کۆمەڵەیەکی بچووکتر
  بۆ شوێنی دووەم (بۆ ساتی فێڵ).
- **مۆبایلەکان:** دوو مۆبایلی ئەندرۆید، ئەپەکە دامەزراوە، ڕێگەی کامێرا و شوێن دراوە، پڕ شەحن کراون، «بێ بێزارکردن» (Do Not Disturb).
- **یەک خول بە مۆدێلی ڕاستەقینە** هەمووی سیناریۆکە (بەشی ٣) لە سەرەتاوە تا کۆتایی، ئینجا **ڤیدیۆی یەدەگ** تۆمار بکەن:
  تۆمارکردنی شاشەی هەردوو مۆبایل و داشبۆرد، یان کامێرایەک کە مۆبایلەکان و پرۆجێکتەر پێکەوە دەگرێت.
  کۆپییەک لەسەر دێسکتۆپی لاپتۆپ و یەکێک لەسەر USB.
- **دوای ئەو خولە، دووریی ساتی فێڵ بپشکنە.** فەرمانی بەشی ٤ تەنها کاتێک `reused_media` دەدات کە شوێنی دووەم زیاتر لە ٥٠ مەتر
  (`CLEANUP_RADIUS_M`) لە ڕاپۆرتی پاککراوە دوور بێت، بە پێی ئەو GPS ەی پاشەکەوت کراوە. هەمان دوو شوێن کە فەرمانەکە
  هەڵیاندەبژێرێت:

  ```bash
  cd backend && source .env
  psql "$DATABASE_URL" -c "SELECT round(ST_Distance(
      (SELECT r.location FROM cleanups c JOIN reports r ON r.id = c.report_id
        WHERE c.verdict = 'verified' ORDER BY c.id DESC LIMIT 1),
      (SELECT location FROM reports WHERE status = 'open' ORDER BY id DESC LIMIT 1))) AS metres"
  ```

  دەبێت زۆر لە ٥٠ زیاتر بێت (~١٠٠ یان زیاتر). ئەگەر نزیک ٥٠ بوو، GPS ی ناو هۆڵ لە ڕۆژی دیمۆدا دەتوانێت بیخاتە ژێر ٥٠ ەوە:
  شوێنی دووەم دوورتر هەڵبژێرە.

## ٢. یەک کاتژمێر پێش

١. **هۆتسپۆت:** مۆبایلێکی سێیەم (ئەگەر هەبێت داتای مۆبایلی هەبێت). لاپتۆپ و مۆبایلی A و B پەیوەست بن پێوەی، نەک بە Wi-Fi ی هۆڵ.

٢. **پەنجەرەی یەکەم — داتابەیسی پاک و سێرڤەر بە مۆدێلی ڕاستەقینە:**

   ```bash
   cd backend && source .env
   python seed.py     # هەموو شتێک دەسڕێتەوە: نەخشەی پاک بۆ دیمۆ
   python run.py      # واتە MODEL_PATH=models/slemani.pt LITTER_CLASSES=* python run.py
   ```

   ئەگەر نووسی `Port 5000 is occupied ... Using port 5001`، لە هەموو شوێنێکی خوارەوە 5001 بەکاربهێنە.

٣. **پەنجەرەی دووەم — preflight:**

   ```bash
   cd backend && source .env
   python tools/preflight.py --model --server http://localhost:5000
   ```

   دەبێت دوا هێڵ `0 ✗ ... ئامادەیە` بێت. هێڵی «IP ی لاپتۆپ» و «ناونیشان بۆ مۆبایلەکان» ئەو ناونیشانەن کە لە مۆبایل دەنووسرێن
   (ئەگەر چەند دانەیەک بوون، ئەوەی هۆتسپۆتەکە: زۆرجار `192.168.x.x`، هۆتسپۆتی iPhone `172.20.10.x`).

٤. **مۆبایلەکان:** لە وێبگەڕی مۆبایل `http://<IP>:5000/health` بکەرەوە، دەبێت `"ok": true` نیشان بدات.
   ئەگەر نەیکردەوە: فایەروۆڵی لاپتۆپ ڕێگە بە Python بدات، یان مۆبایل لەسەر هۆتسپۆتەکە نییە.

٥. **هەژمار:** `seed.py` هەموو هەژمارەکانی سڕییەوە، بۆیە لە ئەپەکە **دەربچن** و دووبارە هەژماری نوێ دروست بکەن:
   مۆبایلی A دەریا، مۆبایلی B دادیار، دوو هاوڵاتیی جیاواز (باشترە لە دوو گەڕەکی جیاواز، بۆ ئەوەی لیگ بجووڵێت).
   ژمارە و وشەی نهێنیی هەردووکیان لەسەر کارتێک بنووسن.

٦. **شوێنی دیمۆ:** زبڵدانەکە بە ستیکەری QR، کەرەستەکان لە دەوری. شوێنێک هەڵبژێرن کە نەخش و وردەکاریی تێدابێت
   (کاشی، پۆستەر، کورسی)، نەک دیواری سپی: پشکنینی «هەمان شوێن» (ORB) پێویستی بە گۆشە هەیە.
   هەردوو مۆبایل لەسەر نەخشە چاوەڕێی GPS بکەن؛ لە ناو هۆڵ نزیک دەرگا یان پەنجەرە باشترە (سنوور ٥٠ مەترە).

٧. **شوێنی دووەم (بۆ ساتی فێڵ):** **دادیار** (مۆبایلی B، نەک دەریا) ئێستا کۆمەڵە بچووکەکە ڕاپۆرت دەکات، **لە دەرەوەی هۆڵ**
   (GPS ی باشتر) و **لانیکەم ~١٥٠ مەتر** دوور لە زبڵدانەکە. هۆکار: فەرمانی ساتی فێڵ تەنها لە دووری زیاتر لە ٥٠ مەتر
   `reused_media` دەدات، و GPS ی ناو هۆڵ دەتوانێت دەیان مەتر هەڵە بێت. ئەگەر دوو ڕاپۆرت لە ٣٠ مەتردا بن، ڕاپۆرتی زیندووی
   سەر شانۆ دەبێت بە «پشتڕاستکردنەوە»ی ئەم ڕاپۆرتە؛ و ئەگەر هەردووکیان هی دەریا بن، ڕاپۆرتی زیندوو بە
   `already_reported_by_you` («تۆ پێشتر ئەم شوێنەت ڕاپۆرت کردووە») ڕەت دەکرێتەوە. ئەگەر پرسیار کرا، ڕاستی بڵێن کە پێشوەختە کراوە.

٨. **داشبۆرد لەسەر پرۆجێکتەر:** `http://localhost:5000/dashboard` ← هەژماری شارەوانی `07500000000` و `STAFF_PASSWORD` ی
   `.env` (لەسەر کارتەکەیە). نەخشە لەسەر هۆڵەکە زووم بکە، F11. هەر ١٠ چرکە نوێ دەبێتەوە.

٩. **فەرمانی فێڵ** (بەشی ٤) لە پەنجەرەی دووەم ئامادە بکە. **ڤیدیۆی یەدەگ** لە پلەیەرێک کراوە و لەسەر ٠:٠٠ وەستاو.
   لاپتۆپ بە کارەبا، خەو (sleep) کوژاوە، ئاگادارکردنەوەکان کوژاون.

## ٤. ساتی فێڵ: هەمان ڤیدیۆ بۆ شوێنێکی تر

ئەپەکە گەلەری نییە، بۆیە فێڵبازێک دەبێت ئەپەکە تێپەڕێنێت. ئەم فەرمانە هەر ئەوە دەکات: ٨ فریمەکەی دوایین پاککردنەوەی
سەلمێنراو دەنێرێت بۆ نوێترین شوێنی کراوە (شوێنی دووەم)، بە GPS ی ئەو شوێنە (وەک ئەوەی GPS یش ساختە کرابێت)،
بە هەژمارێکی نوێی «فێڵباز». لە `backend/` و دوای `source .env`؛ پێش دیمۆ بیلکێنە، Enter ی کۆتایی لەسەر شانۆ:

```bash
python - http://localhost:5000 <<'EOF'
import random, sys
import psycopg, requests
from app.config import Config
base = sys.argv[1]
with psycopg.connect(Config.DATABASE_URL) as db:
    done = db.execute("SELECT frame_paths FROM cleanups WHERE verdict = 'verified' ORDER BY id DESC LIMIT 1").fetchone()
    spot = db.execute("SELECT id, ST_Y(location::geometry), ST_X(location::geometry) FROM reports "
                      "WHERE status = 'open' ORDER BY id DESC LIMIT 1").fetchone()
if not done or not spot:
    sys.exit("need one verified cleanup and one open spot")
phone = "07" + "".join(random.choices("0123456789", k=9))
auth = {"Authorization": "Bearer " + requests.post(f"{base}/auth/signup", json={
    "name": "فێڵباز", "phone": phone, "password": "secret123", "neighbourhood_id": 1}).json()["token"]}
challenge = requests.post(f"{base}/reports/{spot[0]}/claim", headers=auth).json()
files = [("frames", (n, open(f"{Config.UPLOAD_DIR}/{n}", "rb"), "image/jpeg")) for n in done[0]]
r = requests.post(f"{base}/reports/{spot[0]}/cleanup", headers=auth, files=files,
                  data={"lat": spot[1], "lon": spot[2], "challenge_id": challenge["id"]}).json()
print(f"spot {spot[0]}: {r['verdict']} ({r['reason_code']}) {r['message']}")
EOF
```

ئەنجامی چاوەڕوانکراو: `spot N: rejected (reused_media) ئەم وێنە یان ڤیدیۆیە پێشتر نێردراوە`. شوێنی دووەم کراوە دەمێنێتەوە.
پشکنینی دووبارە پێش AI دێت، بۆیە بەستراو نییە بە مۆدێلەکە؛ تەنها فریمە QR ەکان ناژمێردرێن، بۆیە لە کاتی تۆمارکردندا
QR هەموو کاتێک لە وێنەدا نەبێت. لە خولی ئێوارەی پێشوودا جارێک تاقی بکەنەوە.

## ٥. ئەگەر شتێک تێکچوو

| کێشە | چی دەکەین |
| --- | --- |
| ئینتەرنێتی هۆڵ نییە | هیچ: هۆتسپۆتەکە ناوخۆییە؛ سێرڤەر، مۆدێل، داشبۆرد (Leaflet لە ناو ئەپەکەدایە) و ئەپ بێ ئینتەرنێت کار دەکەن. تەنها وێنەی پاشبنەمای نەخشە (OSM) ئینتەرنێتی دەوێت: داتای مۆبایلی هۆتسپۆتەکە؛ یان داشبۆرد پێشتر لەسەر هەمان ناوچە بکەرەوە، وێبگەڕ زۆرجار وێنەکان لە کاشدا دەهێڵێتەوە. بێ ئەوانیش خاڵەکان لەسەر پاشبنەمای خۆڵەمێشی دەردەکەون. `DESCRIBE_WITH_CLAUDE` کوژاوە بمێنێتەوە. |
| مۆدێلی ڕاهێنراو باشتر نییە | ئێوارەی پێشوو بە `tools/evaluate.py` بڕیار بدەن و مۆدێلی گشتیی پاشماوە بەکاربهێنن (`MODEL_PATH=models/yolov8m-seg.pt LITTER_CLASSES=*`)؛ بە ڕاستی بیڵێن و ژمارە ڕاستەقینەکان پیشان بدەن. |
| «هەمان شوێن» متمانەپێکراو نییە | ئەنجام «نێردرا بۆ پشکنین» دەبێت، نەک ڕەتکردنەوە: زانکۆ لە کارتی پشکنینی داشبۆرد پەسەندی دەکات ← سەوز (مرۆڤ لە خولەکەدا تایبەتمەندییە). تۆمارکردن لە هەمان گۆشەی وێنەی ڕاپۆرت. `SAME_PLACE_MIN_INLIERS` لەسەر شانۆ مەگۆڕن. |
| کێشەی ئەپ لەسەر یەک مۆبایل | مۆبایلە باشەکە هەردوو ڕۆڵ: ڕاپۆرت بە هەژماری A، دەرچوون، چوونەژوورەوە بە هەژماری B (کارتەکە)، پاککردنەوە. ~٣٠ چرکە زیاتر. |
| GPS لە ناو هۆڵ (`too_far`) | هەردوو مۆبایل لە هەمان خاڵ، نزیک دەرگا/پەنجەرە، چاوەڕێی GPS؛ پێش دیمۆ تاقی بکەنەوە. |
| سێرڤەر وەستا | `python run.py` لە پەنجەرەی یەکەم (هەمان `.env`): داتا لە PostgreSQL دایە و مۆبایلەکان دەرناکرێن. |
| دیمۆی زیندوو سەرکەوتوو نەبوو | تەنها یەک هەوڵی تر. پاشان ڕەند: «دوێنێ هەمان خولمان تۆمار کرد» و ڤیدیۆی یەدەگ. لەسەر شانۆ هەڵە چاک مەکەن. |

## ٦. هەرگیز لەسەر شانۆ

- **`DETECTOR_KIND=colorblob`** — کاغەزی سوور دەژمێرێت، نەک پاشماوە. preflight ✗ دەدات.
- **`SIM_CAMERA=1`** — وێنەی دروستکراو بۆ سیمولەیتەر. preflight ✗ دەدات، و سێرڤەری کاراوەش دەپشکنێت.
- **ڕیپۆی ڕاهێنان** (ئەم ڕیپۆیە) — یاسای هاکاسۆن: هەر شتێک پێشکەش دەکرێت دەبێت لە ٨ و ٩ی تشرین دروست کرابێت.
  دیمۆ لە ڕیپۆی هاکاسۆنەوە، کۆد و commit ی ئێرە لەسەر شاشە نا.
- `tools/rehearse.py` یان `tools/fraud_bench.py` لەسەر سێرڤەر یان داتابەیسی دیمۆ: شوێن و هاوڵاتیی دروستکراو دەخەنە سەر نەخشەی ڕاستەقینە.
- `seed.py` دوای ئەوەی مۆبایلەکان هەژماریان دروست کرد: هەمووی دەسڕێتەوە.

## ٧. ڕاهێنان بێ مۆبایل (پێش ڕۆژی دیمۆ)

لەسەر داتابەیسێکی جیا، نەک هی دیمۆ:

پەنجەرەی یەکەم:

```bash
cd backend
export DATABASE_URL=postgresql://gl:gl@localhost:5432/greenlegacy_rehearsal   # CREATE DATABASE + CREATE EXTENSION postgis
python seed.py
DETECTOR_KIND=colorblob python run.py
```

پەنجەرەی دووەم (`export` ی پەنجەرەی یەکەم لێرە نییە، بۆیە preflight بێ `DATABASE_URL` داتابەیسی دیمۆ دەپشکنێت نەک ئەم):

```bash
cd backend
DATABASE_URL=postgresql://gl:gl@localhost:5432/greenlegacy_rehearsal DETECTOR_KIND=colorblob \
    python tools/preflight.py --rehearsal --server http://localhost:5000     # دەبێت 0 ✗ بێت
python tools/rehearse.py http://localhost:5000
```

دۆخی چاوەڕوانکراوی هەر هەنگاوێک: report `201`، claim by reporter `403`، claim `201`، wrong order `200` (ڕێنمایی جێبەجێ نەکرا)،
correct `200` (سەلمێنرا)، old video `200` (پێشتر نێردراوە)، other place `200` (بۆ پشکنینی مرۆیی).
ئەنجامی ٨ی تشرین: سێ خولی یەک لە دوای یەک، هەموو هەنگاوەکان وەک چاوەڕوانکراو، هەر خولێک نزیکەی ٣ چرکە.
